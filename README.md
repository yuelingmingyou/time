# 事件档案室 · Chronicle Archive

档案风的可编辑时间轴网站。**单文件**：全部样式与逻辑都内联在 `index.html` 中，零依赖、零构建，可直接部署到 GitHub Pages。

## 功能

- **时间轴**：按 `order` 排序的事件档案袋，支持按标签 / 人物筛选与关键词检索
- **事件详情**：点击时间轴卡片 → 打开完整卷宗（带打孔、印章、档案表格）
- **人物档案**：正文中标蓝的人名可点击 → 跳转人物设定页；人物页自动列出相关卷宗
- **涂黑条**：`[[x:文字]]` 渲染为遮盖黑条，鼠标悬停显示
- **编辑模式**：网页右上角开启，可增删改事件与人物（仅保存在当前浏览器），支持导出 / 导入 / 恢复初始数据

## 文件结构

```
├── index.html      ★ 全部内容（页面 + 样式 + 数据 + 逻辑）
└── README.md
```

`index.html` 内部结构（按顺序）：

1. `<style>` —— 全部样式
2. 页面骨架 `<body>`
3. 第一段 `<script>`：`window.ARCHIVE_DATA = {...}` —— **★ 全部网站内容都在这里**（站点标题、事件、人物），改它即可更新网站，字段注释写在数据块上方
4. 第二段 `<script>` —— 渲染与编辑逻辑（一般无需修改）

## 修改内容（两种方式）

**方式一：直接改文件（永久生效，推荐）**
编辑 `index.html` 中 `window.ARCHIVE_DATA = {...}` 数据块，提交推送即可。

**方式二：网页编辑模式（先预览效果）**
1. 打开网站，右上角点「✎ 编辑模式」
2. 增删改事件 / 人物，页面实时更新（保存在浏览器 localStorage，不影响他人）
3. 满意后点底部「导出 data.js」，得到完整数据块
4. 用其中的 `window.ARCHIVE_DATA = {...};` 整段**替换 `index.html` 里原有的数据块**，提交推送

### 正文特殊标记（在 `article` / `bio` 中可用）

| 标记 | 效果 |
|---|---|
| `[[c:人物id\|显示文字]]` | 可点击人名，跳转人物档案 |
| `[[e:事件id\|显示文字]]` | 可点击事件名，跳转事件卷宗 |
| `[[x:文字]]` | 黑条遮盖，悬停显示 |

## 部署到 GitHub Pages

1. 新建仓库，上传 `index.html`（就这一个文件）
2. 仓库 → `Settings` → `Pages` → `Source` 选择 `Deploy from a branch`，分支选 `main` / 根目录 `/ (root)`
3. 保存后稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`

> 单文件意味着也可以直接丢进任何静态托管（Vercel / Netlify / Cloudflare Pages）、Gist 转发的静态服务，甚至双击本地打开都能运行。
